# Figma Make reference notes

This export uses React, Vite and Tailwind CSS. Its files are stored directly in
this directory: `App.tsx`, `index.css`, `main.tsx` and `package.json`.

The export does not include the original hosted preview environment or a
complete standalone build configuration. Hosted-server commands and `src/` paths
from that environment do not describe this checkout.

Use `App.tsx` and `index.css` as read-only design references. Native frontend
implementation and testing belong in [mobile/](../../mobile/README.md).
Prototype authentication and data interactions are demonstrations; consult the
mobile README for the native app's actual behavior and limitations.
