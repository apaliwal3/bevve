# Milan bars CSV

`milan-bars-50.csv` is formatted for the app's `public.bars` table as defined by migrations 001–006 in `bevve-backend/supabase/migrations/`. It contains 50 distinct real venues in Milano, Italy, researched on **25 November 2026**.

## Import columns

```text
name,address,latitude,longitude,is_demo,area,city,vibe,image_url,opening_hours_label,is_popular
```

| Column | Value |
| --- | --- |
| `name` | Researched public venue name, distinguishing branches. |
| `address` | Published street address, postal code when established, city, and country. |
| `latitude`, `longitude` | Reviewed map coordinates in decimal degrees. |
| `is_demo` | `false` for every real venue. |
| `area` | Map neighborhood/quarter associated with the reviewed location. |
| `city` | Milano. |
| `vibe`, `image_url`, `opening_hours_label` | Empty, representing SQL NULL, because these fields were not consistently established. |
| `is_popular` | `false`, the table's default editorial flag; no popularity claim is inferred from research. |

`id` and `created_at` are omitted so PostgreSQL generates their existing UUID and timestamp defaults. The CSV contains only actual `bars` columns; the original category, contact details, and source information are preserved in the separate reference file.

The file uses UTF-8, comma-separated fields, standard CSV quoting, and one header row plus 50 data rows. It is designed for an initial insert: each import receives newly generated IDs.

Use Supabase Table Editor's CSV import for `public.bars`, mapping headers to the matching columns and keeping empty optional fields as NULL. Import through an account with catalog write privileges; the app's authenticated role has read access to this table.

## Coordinate sources and precision

Coordinates were reviewed against venue names and researched addresses. Similar-name businesses, results outside Milano, and street-center results were rejected. The selected locations are:

- 40 venue map points.
- 6 host-hotel map points for bars inside those hotels.
- 3 verified address/entrance points: Deus Café Isola, Mio Lab, and Morgan's Milano.
- 1 publisher map pin for Bar Nico, cross-checked against a second published coordinate.

These are map locations suitable for discovery and approximate distance calculation. A host-hotel or entrance point represents the building location; rooftop floors are not encoded. Map coordinates are not surveyed GPS measurements.

OpenStreetMap coordinate data: **© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)**, available under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/). Lookups used a single-threaded, cached, one-time process limited to less than one request per second, following the [Nominatim usage policy](https://operations.osmfoundation.org/policies/nominatim/). Bar Nico's selected pin is from [TuttaMilano](https://www.tuttamilano.it/bar-nico-milano-49510), corroborated by [The Direct Index](https://directindex.org/r/barnicomilano.com).

## Reference file

`milan-bars-50.sources.csv` preserves the original 15 research columns and adds latitude, longitude, coordinate match type, coordinate source URL, geocoding query URL, and coordinate research date. Match rows by their unique `name` values. This file is a reference dataset and includes columns outside the app's schema.

Each row includes a supporting venue source URL. Forty-one rows use a venue's or operator's official website as their primary source. The other nine use a tourism board, district guide, publisher, business listing, event organizer, or brand partner, identified in `source_type`. Additional supporting pages appear in `additional_source_urls`, separated by ` | `.

Details were transcribed from public web pages and search-indexed page content. The research date records when sources were consulted; it is not their publication date or a guarantee of current operation. Known permanent closures found during research were excluded. Contact numbers and email addresses were not tested by contacting businesses. Empty reference cells mean unavailable, unconfirmed, or omitted because sources conflict.

MAG I Navigli and Backdoor43 are separate venues at the same address. BOB and BOB - The Other Side are separate adjacent venues. Hotel bars and visitor-entrance qualifications are recorded in the reference notes.

## Validation

The CSV was imported into a temporary local PostgreSQL database using all six app migrations. Validation checked that:

- All 50 rows import with the table's actual constraints.
- UUIDs and creation timestamps are generated by the database.
- Empty optional metadata imports as NULL.
- All 50 results from `get_venue_catalog` pass the app's shared mobile decoder.

The hosted catalog and application source code were not modified.
